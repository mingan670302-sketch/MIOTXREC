01

快速開始

依照電腦系統選擇啟動方式。

⊞Windows

  1. 完整解壓縮 MIOTXREC-Windows-Installer.zip，請勿直接在 ZIP 內執行。
  2. 雙擊 一鍵啟動.cmd。
  3. 程式會關閉舊服務、重新啟動並自動開啟瀏覽器。
GitHub 提供的是輕量安裝包，不包含預裝執行環境；第一次啟動會依需要下載 Python 與 PDF 元件，請保持網路連線。

⌘macOS

  1. 完整解壓縮 MIOTXREC-macOS-Installer.zip。
  2. 確認已安裝 Python 3.10 以上版本。
  3. 在 Finder 對 一鍵啟動.command 按右鍵，選擇「打開」。
第一次啟動會依 Intel／Apple Silicon 架構安裝 PDF 元件，需要網路。

03

填寫與回顧交易

表單順序與 PDF 列印版一致。

  1. 第一次使用先設定姓名；之後可點右上角姓名修改。
  2. 確認交易日期，輸入商品、方向、進出場價格與交易計畫。
  3. 進場、出場、事後複盤各可上傳一張 PNG、JPG、WebP 或 GIF，單張上限 10 MB。
  4. 按「儲存交易」。流水號依資料庫順序產生，例如 TR-000001。
  5. 從「交易紀錄」依日期、商品或流水號搜尋，開啟後可再次編輯。
R 值會依方向、入場、止損及出場價格自動換算；未計入手續費、滑價及分批進出場。
04

商品代號自動完成

輸入代號或名稱即可搜尋本機商品清單。

股台股與 ETF

支援上市、上櫃股票與 ETF；選取後保存為「代號 名稱」，例如 2330 台積電、0050 元大台灣50。

期臺指期貨提示

大台 TX、小台 MTX、微台 TMF。其它商品如 BTC/USDT 仍可自由輸入。

05

交易紀錄與 PDF

網頁檢視、PDF 與每日匯出使用一致的欄位順序。

  • 交易詳情採用與 PDF 列印版一致的表格排版。
  • PDF 保留原始 A4 底版，過長內容完整列於附頁。
  • HTML 內嵌交易圖片，可直接離線開啟。
  • 修改交易日期時，匯出檔會移至新的日期資料夾。
  • 姓名更新後，既有 PDF 會同步重新產生。
  • 「重建日期資料夾」可由資料庫重建全部匯出檔。

所有內容均保存在程式旁的「資料」資料夾。

日期資料夾是方便閱讀的匯出副本。請在網頁中修改交易，不要直接修改 PDF、HTML 或 JSON。
07

備份與異機還原

備份資料庫包含全部欄位與原始圖片。

  1. 在左側按 ↓ 備份所有資料 下載一致的 SQLite 備份。
  2. 將備份另外保存至外接硬碟、NAS 或可信任的備份位置。
  3. 還原前先停止服務；保留目前整個「資料」資料夾作為第二份備份。
  4. 將下載檔放入新的「資料」資料夾並改名為 交易紀錄.sqlite3。
  5. 執行「重建日期資料夾」後，再執行一鍵啟動。
不要在服務執行時直接覆蓋資料庫。Windows 與 Mac 版本日後會各自寫入自己的資料庫，不會自動同步。

09

疑難排解

常見狀況與安全處理方式。

瀏覽器沒有自動開啟

先手動開啟 http://127.0.0.1:33968/。若無法連線，再重新執行一鍵啟動。

顯示 33968 連接埠被占用

再次執行一鍵啟動；它會先關閉本資料夾原有的交易手記程序，再重新啟動。若仍失敗，查看 資料／錯誤.log。

LOGO 或畫面沒有更新

Windows 可按 Ctrl＋F5 強制重新整理；Mac 可按 Command＋Shift＋R。

macOS 顯示沒有執行權限

在終端機進入程式資料夾後執行 chmod +x *.command；若受下載隔離限制，可在確認檔案來源後執行 xattr -dr com.apple.quarantine .。

PDF 無法產生

確認第一次啟動時可連線網路，讓程式補齊 PDF 元件。Windows 使用微軟正黑體；macOS 使用 PingFang／Heiti／Songti 系統字型。

資料是否會上傳網路？

交易資料只由 127.0.0.1 本機服務提供，不開放區域網路或外網存取。只有更新股票清單、安裝缺少元件或開啟 YouTube 頻道時需要網路。
